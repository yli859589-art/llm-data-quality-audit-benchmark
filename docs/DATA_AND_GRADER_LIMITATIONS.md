# Data, Grader, and Claim Limitations

## Included data

- Public Tiny Shakespeare text from [`karpathy/char-rnn`](https://github.com/karpathy/char-rnn/tree/master/data/tinyshakespeare).
- Local checksum verification documented in [`data/tinyshakespeare/SOURCE.md`](../data/tinyshakespeare/SOURCE.md).
- Deterministic stress-test corruption generated locally for baseline and ablation experiments.

## Not included

- Private Gradescope tests, Coursera graders, or instructor-only test cases.
- Course-internal notebooks or official solution files.
- Restricted datasets requiring course accounts.
- Production-scale web crawls, distributed training artifacts, or official leaderboard submissions.
- A CMU course rubric or instructor authorization for academic submission.

## Claim boundary

The focused benchmark supports portfolio claims about local reproducibility, controlled data-quality ablations, held-out Tiny Shakespeare metrics, and CPU attention measurements. It does not support claims of production-scale model quality, official competition placement, or institutional certification.

## Usage note

It is appropriate to list this repository as a personal GitHub project. Do not submit it for academic credit unless the target instructor explicitly permits the project, dependencies, external assistance, and disclosure format.
