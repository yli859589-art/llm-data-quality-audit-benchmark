# Experiments

## Quick

```bash
python scripts/run_dataset_matrix.py --mode quick
python scripts/run_quick_experiment.py
```

Quick mode is CPU-oriented, offline, and smoke-test sized. It uses
`tiny_shakespeare` and `mixed_debug` for dataset-matrix checks and one seed
for the default model run.

## Paper-Prototype

```bash
python scripts/run_dataset_matrix.py --mode paper-prototype --dry-run
python scripts/run_multi_seed.py --mode paper-prototype
```

Paper-prototype mode includes all configured dataset entries:
`tiny_shakespeare`, `mixed_debug`, `wikitext2`, `openwebtext_sample`, and
`c4_sample`. Optional public datasets fall back offline unless network access
is explicitly enabled. Dry-run mode validates dataset loading, fallback,
dataset cards, and output routing without claiming model results.

## Full

```bash
python scripts/run_dataset_matrix.py --mode full --allow-network
```

Full mode is intended for later paper conversion. It allows more datasets,
longer training, larger model configs, and more seeds. It should be run only
after reviewing upstream dataset cards and usage policies.

## Generated Research Artifacts

The current quick artifact set includes HDQS sweeps, curriculum diagnostics,
pipeline-order diagnostics, retention/PPL rows, privacy-utility rows,
downstream metrics, generation samples, multi-seed tables, failure analysis,
and SVG figures. All tables and figures are generated by scripts.

## Interpretation Boundary

Standalone HDQS is not claimed as consistently better than raw data in quick
mode. The stronger preliminary observation is the combined full pipeline, and
that still requires multi-dataset, multi-seed verification before paper-level
claims.
