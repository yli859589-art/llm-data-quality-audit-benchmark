# DataAudit-LM Project Overview

DataAudit-LM is a reproducible benchmark for auditing LLM pretraining-data
filters under controlled training budgets.

The project studies whether filtering methods improve language-model utility
when data, tokenizer, model shape, seed, and token budget are held fixed. The
current reusable evidence covers 2 datasets, 7 methods, 3 seeds, and 42
completed training runs.

The repository emphasizes traceable artifacts: manifests, filter decisions,
training metrics, evaluation tables, statistical summaries, and integrity
reports.
