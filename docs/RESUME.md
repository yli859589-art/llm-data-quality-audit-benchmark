# Resume-Safe Project Description

## English

**LLM Data Quality Benchmark Platform | Python, PyTorch, NumPy**

- Built a reproducible research prototype for LLM data-quality benchmarking,
  including controlled and pseudo-real web-noise injection, exact/Jaccard/
  MinHash-LSH deduplication, HDQS++ document scoring, DQCS curriculum
  diagnostics, pipeline-order studies, privacy-utility analysis, and
  equal-budget MiniGPT training.
- Implemented dataset-matrix, multi-seed, statistical-analysis, artifact
  validation, coverage, lint, type-check, CI, and zip-export hygiene workflows.
- Generated JSON/CSV/Markdown/SVG artifacts for quick-mode results, HDQS
  sweeps, ablations, dataset cards, privacy checks, downstream metrics,
  generation samples, and failure analysis.

## 中文

**LLM 数据质量 Benchmark 平台 | Python, PyTorch, NumPy**

- 构建可复现的 LLM 数据质量研究原型，支持受控/半真实网页噪声注入、
  精确去重、Jaccard 与 MinHash-LSH 近重复检测、HDQS++ 文档质量评分、
  DQCS curriculum 诊断、pipeline 顺序实验、privacy-utility 分析，以及
  固定预算 MiniGPT 训练对比。
- 实现 dataset matrix、多 seed 统计分析、artifact 校验、覆盖率、lint、
  type check、CI 和 zip-export 卫生检查流程。
- 自动生成 JSON/CSV/Markdown/SVG 证据，包括 quick 结果、HDQS sweep、
  ablation、dataset card、隐私检查、下游指标、生成样例和失败案例分析。
