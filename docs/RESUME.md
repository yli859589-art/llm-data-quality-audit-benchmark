# Resume-Safe Project Description

## English

**LLM Data Quality Benchmark Platform | Python / PyTorch / NumPy**

- Built a reproducible AI benchmark for small-scale language-model pretraining,
  covering deterministic and pseudo-real web-noise injection, synthetic PII
  redaction, exact/Jaccard/MinHash-LSH deduplication, HDQS++ document-quality
  scoring, DQCS curriculum diagnostics, pipeline-order ablations, equal-budget
  training, multi-seed statistics, privacy-utility analysis, and an auxiliary
  attention systems benchmark.
- Implemented a paper-prototype dataset matrix with real local small runs,
  explicit fallback records for optional remote datasets, paired statistical
  tests, model-scaling artifacts, downstream proxy reports, failure analysis,
  and generated JSON/CSV/Markdown/SVG research artifacts.
- Added repository-quality workflows including unit tests, coverage reporting,
  ruff, mypy, Black configuration, GitHub Actions CI, artifact validation, and
  repository hygiene checks.
