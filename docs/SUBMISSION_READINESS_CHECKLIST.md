# Submission Readiness Checklist

## Current status

This repository is ready to present as a personal, public-course-inspired implementation portfolio after local verification passes. Eligibility for a specific graded course assignment or competition remains undetermined until the official rubric and instructor policy are checked.

## Required course-specific inputs

Before submitting this repository for academic credit, obtain and review:

- The official assignment or competition rubric.
- The permitted deliverable format and required directory structure.
- The required dataset, baseline, scoring metric, and leaderboard rules.
- The allowed dependencies, compute budget, and external-resource policy.
- The instructor's policy for collaboration, code reuse, and AI-assisted development.
- The due date, submission portal, and any required report or presentation format.

## Academic integrity review

Carnegie Mellon University's [Academic Integrity Policy](https://www.cmu.edu/policies/student-and-student-life/academic-integrity.html) states that academic credit should represent the student's own work, that assistance on graded work requires instructor authorization, and that sources and permitted assistance must be acknowledged.

Before an academic submission:

- Confirm in writing that this project type is allowed for the course or competition.
- Confirm whether AI-assisted review, debugging, and documentation edits are permitted.
- Complete `docs/PROVENANCE_AND_ASSISTANCE.md` accurately.
- Cite public references, starter code, datasets, and external assistance.
- Do not describe this repository as CMU coursework unless it was accepted for that purpose by the instructor.

## Engineering verification

- Run `python scripts/run_verification.py`.
- Run `python scripts/run_experiments.py`.
- Inspect `docs/LATEST_SELF_CHECK_RESULTS.json`.
- Replace toy data with the rubric's dataset when required.
- Add rubric-specific baselines, metrics, ablations, and error analysis.
- Preserve Git history and attach the required report artifacts.

## Portfolio wording

Use: `Personal AI/ML open-course-inspired implementation suite`.

Avoid claims of official affiliation, hidden-grader completion, leaderboard placement, or institutional certification unless independently verified.
