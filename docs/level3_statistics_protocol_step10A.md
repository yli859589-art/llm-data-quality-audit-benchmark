# Level 3 Statistics Protocol Step 10A

The statistics protocol prevents single-run or unstable differences from being
reported as robust method gains.

## Required Statistics

- Mean and standard deviation.
- Confidence intervals.
- Bootstrap confidence intervals.
- Paired differences.
- Rank correlation.
- Seed variance.
- Multiple-seed reporting.
- Insufficient-sample warnings.
- Method-ranking stability.

## Claim Rules

- n=1 significance claims are not allowed.
- A confidence interval crossing zero blocks an improvement claim.
- Ranking must include uncertainty.
- Invalid sample sizes must not receive p-value claims.
