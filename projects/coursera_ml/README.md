# Classical Machine Learning and Recommender Systems

This project family implements CPU-friendly ML examples inspired by public introductory machine-learning project themes.

## Implemented components

- Linear regression and logistic regression.
- Softmax classification and small neural-network utilities.
- Decision-tree-style classification helpers.
- K-Means clustering and anomaly detection.
- Collaborative filtering / matrix-factorization style recommendation.
- Bandit/RL-style compact experiment.

## Run

```bash
python all_course_projects.py --self-check --json
```
