# AI Search, Multi-Agent Decision Making, RL, and Inference

This project family implements compact, runnable AI components inspired by public Pac-Man-style AI project themes.

## Implemented components

- Grid-world state representation and transition utilities.
- BFS, UCS, A*, and Corners-style heuristic search.
- Minimax and alpha-beta multi-agent decision logic.
- Value iteration and Q-learning on a deterministic MDP.
- HMM forward filtering, Viterbi decoding, and particle-filter-style abstractions.
- Perceptron-style ML classification check.

## Run

```bash
python all_course_projects.py --self-check --json
```
