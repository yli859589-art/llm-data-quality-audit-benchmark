# NLP, Word Vectors, Parsing, and GPT-Style Modeling

This project family implements NLP fundamentals inspired by public deep-learning-for-NLP project themes.

- Negative-sampling loss utilities.
- Transition-based dependency parsing helpers.
- GPT-style decoder forward and generation utilities.
- ROUGE-L-style sequence evaluation.
