# Computer Vision and Deep-Learning Building Blocks

This project family implements from-scratch neural-network components inspired by public deep-learning-for-computer-vision project themes.

## Implemented components

- kNN, SVM loss, softmax loss, and two-layer neural network.
- Affine, ReLU, batch normalization, dropout, convolution, and max-pooling layers.
- Forward/backward checks for representative differentiable components.
- RNN step, scaled dot-product attention, contrastive loss, and diffusion forward process.

## Run

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

## Resume note

This is a compact implementation and verification suite. It should not be described as official CS231n assignment submission or hidden-grader completion.
