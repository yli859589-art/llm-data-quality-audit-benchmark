# Language-Modeling Systems Foundations

This project family implements core language-modeling systems utilities inspired by public language-modeling-from-scratch project themes.

## Implemented components

- Byte-pair encoding tokenizer utilities.
- Transformer/GPT-style language-model pieces.
- AdamW optimizer behavior and attention-system checks.
- Scaling-law fitting utilities.
- Data cleaning, deduplication, and PII-removal helpers.
- Preference/alignment loss utilities including DPO-style loss.

## Run

```bash
python all_course_projects.py --self-check --json
```

## Resume note

Present this as a local CPU-friendly LLM systems foundation project. Do not claim distributed GPU training, official hidden-grader completion, or large-scale Common Crawl pretraining.
