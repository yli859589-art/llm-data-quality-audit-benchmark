# Deep-Learning Textbook-Style Components

This project family implements small, readable deep-learning utilities inspired by open textbook-style learning paths.

## Implemented components

- Linear regression and softmax regression.
- Simple MLP/CNN-style utilities.
- Convolution and attention helpers.
- Deterministic local checks with synthetic data.

## Run

```bash
python all_course_projects.py --self-check --json
```

## Resume note

Present this as a from-scratch learning component library, not as a full replacement for any multi-framework textbook codebase.
